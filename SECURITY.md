# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

When GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a private report. Maintainers should enable that GitHub feature before accepting external vulnerability reports.

If private reporting is not available yet, do not include exploit details, credentials, user mappings, diagnostics, certificates, private keys, or personal paths in a public issue. Wait for a private reporting channel to be enabled.

For non-sensitive bugs and product ideas, use the standard issue templates.
