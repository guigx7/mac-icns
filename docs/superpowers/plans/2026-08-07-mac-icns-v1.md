# MacICNS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a signed, native macOS app that maps `.app` bundles to `.icns` files and automatically repairs their custom Finder icons after application updates.

**Architecture:** A SwiftUI main app owns persistence, the mapping UI, repair scheduling, filesystem monitoring, and a `MenuBarExtra`. A narrowly scoped root launch daemon, registered once with `SMAppService`, exposes a Mach XPC endpoint that only applies a validated icon request from the signed app. The main process detects replacements and requests repair through that helper.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Foundation, ServiceManagement, Security, XPC, XCTest, Xcode 16+.

## Global Constraints

- Support macOS 14 Sonoma and later.
- All product-facing copy is English.
- Follow system light/dark appearance with a monochrome visual system.
- Accept local `.app` and `.icns` selections from any user-accessible folder.
- Never store passwords, authorization references, or arbitrary commands.
- The root helper accepts only validated application/icon paths from the signed MacICNS client.
- Keep mappings and diagnostics local; do not send telemetry.
- Use conventional commits after every independently testable task.
- Full Xcode is required; a Developer ID certificate and Team ID are intentionally deferred until the release task.

## File Structure

- `MacICNS.xcodeproj/` — Xcode project containing the app, helper daemon, and test targets.
- `MacICNS/App/` — SwiftUI app lifecycle, app state, and menu bar integration.
- `MacICNS/Domain/` — Codable mapping model, fingerprints, status, and repair request/result types.
- `MacICNS/Data/` — Application Support JSON persistence and diagnostic logging.
- `MacICNS/Services/` — application locating, icon inspection, repair coordination, FSEvents monitoring, and Service Management client.
- `MacICNS/UI/` — focused SwiftUI views for mappings, editor, status, and Settings.
- `MacICNSHelper/` — root-only XPC listener and icon application implementation.
- `Shared/` — `@objc` XPC protocol and request/reply value objects shared by app and helper.
- `Resources/LaunchDaemons/com.guigx.macicns.helper.plist` — bundled launch-daemon definition using `BundleProgram`.
- `MacICNSTests/` — deterministic XCTest coverage for domain, persistence, locating, and repair scheduling.
- `scripts/archive.sh` — reproducible archive/export validation for signed release builds.
- `README.md` — install, required permission, icon-repair behavior, removal, and future Homebrew Cask directions.

```swift
struct IconMapping: Codable, Equatable, Identifiable, Sendable {
    let id: UUID
    var applicationURL: URL
    var bundleIdentifier: String?
    var iconURL: URL
    var appFingerprint: String?
    var iconFingerprint: String?
    var lastSuccessAt: Date?
    var status: MappingStatus
    init(applicationURL: URL, bundleIdentifier: String?, iconURL: URL) {
        self.id = UUID()
        self.applicationURL = applicationURL.standardizedFileURL
        self.bundleIdentifier = bundleIdentifier
        self.iconURL = iconURL.standardizedFileURL
        self.appFingerprint = nil
        self.iconFingerprint = nil
        self.lastSuccessAt = nil
        self.status = .upToDate
    }
}

protocol MappingRepository: Sendable {
    func load() throws -> [IconMapping]
    func save(_ mappings: [IconMapping]) throws
}
```

Store JSON at `Application Support/MacICNS/mappings.json`, create its parent directory with `.applicationSupportDirectory`, and decode a missing file as an empty array.

- [ ] **Step 3: Implement XPC protocol, validation, and helper listener**

Use an `NSObject, NSSecureCoding` request object containing only standardized application and icon file URLs. Require `.app` and `.icns` extensions, existing regular files/directories, non-symlink traversal outside their standardized paths, and an `NSImage(contents:)` that loads successfully. The helper must create `NSXPCListener(machServiceName: "com.guigx.macicns.helper")`, validate the connecting client’s audit token/code-signing requirement in `shouldAcceptNewConnection`, and expose exactly this operation:

```swift
@objc protocol IconHelperXPCProtocol {
```

The helper applies the image with `NSWorkspace.shared.setIcon(_:forFile:options:)`; it must not execute shell commands, accept a command string, or modify a path not supplied in the validated request.
